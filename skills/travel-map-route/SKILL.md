# Travel Map Route

把一批候選見聞錄排成順暢的逐日動線草案，並評估套票划不划算。**不寫 Notion，只計算與建議。**

## 何時改用其他 skill
- 要「查」候選點有哪些、地方誌的票券資訊 → `travel-map-query`
- 候選點還沒建立（沒有見聞錄記錄）→ 先用 `travel-map-knowledge-capture`
- 候選點內容/座標/評分還沒查證 → 先用 `travel-map-page-content` 補
- 排好之後要「實際寫進行程項目」→ `travel-map-trip-planner`（本 skill 只出草案，不寫入）

## 開工前必讀

`travel-map-query/schemas/travel_map_schema.yaml` —— 座標欄位格式、建議停留欄位在這裡。

`assets/scripts/route_planner.py`（本 skill 目錄下）—— 地理排序與分天的計算工具，見下方用法。

## 流程

### 1. 收集候選點
1. 用 `travel-map-query` 撈這趟旅程（或指定城市/區域）底下的候選點：優先抓已經是該旅程 `行程項目`（狀態=候選/待確認）的項目；如果旅程還沒排、只是在探索階段，改抓 `見聞錄` 裡 `所屬地方誌` 符合、`收集狀態`＝已整理 的項目
2. **跳過所屬地方誌還掛在「📥 待分類（Inbox 佔位）」的項目**——連城市都沒確定就無法排動線，請使用者先確認
3. 檢查每個候選點有沒有 `座標`：沒有座標的列出來，跟使用者說「這幾個沒座標排不了動線，要不要先讓 page-content 補」，不要自己憑地名腦補座標

### 2. 用 route_planner.py 算草案
1. 把候選點整理成 JSON（欄位：`name`/`座標`/`建議停留`，`must_visit` 可選，見聞錄的 `標籤`＝必去景點時設 true）
2. 執行：`python3 assets/scripts/route_planner.py candidates.json --day-hours <這趟每天想排的時數，沒說就用 9> --speed <walking/transit/driving，看這趟是不是自駕>`
3. 這支 script **只算地理距離與時間預算**，用最近鄰貪婪法排序、超過每日時數自動分下一天。它不知道休館日、不知道三餐時間、不知道套票——這些是接下來 agent 自己要做的事，不要以為 script 跑完就結束了

### 3. 人工校正（script 算不出來的部分）
1. **三餐時段**：檢查每天的排序有沒有把類別＝🍽️餐廳 的候選點排在合理的午餐（11:30-13:30）／晚餐（18:00-20:00）時段附近，沒有就手動調整順序，不要讓使用者中午還在博物館裡
2. **開放時間衝突**：讀每個候選點見聞錄正文「蒐集資料」區的營業時間，檢查有沒有休館日撞到排定日期、或排的時間超過最後入場——查不到營業時間的要老實標「未查證，建議出發前再確認」，不要假設營業
3. **同行者飲食限制**：這趟如果 `同行者組合` 包含爸媽/女朋友，餐廳候選要交叉比對 `飲食適配`，`❓ 待確認菜單` 的餐廳排進確定行程前先提醒使用者
4. **必去景點優先**：`must_visit` 的點如果被排到動線很尾端或跟其他天沖堂，主動提出來讓使用者決定要不要調整優先順序

### 4. 套票划算評估
1. 讀該地方誌的「🎫 票券與套票」一節，看有哪些票券、涵蓋哪些點、價格
2. 對照排好的動線，算「這趟候選點裡有幾個在套票涵蓋範圍內」，比較 現場單買總價 vs 套票價格
3. **只給數字和建議，不要幫使用者做決定**——套票常有時間限制或動線綁定，讓使用者自己權衡

### 5. 交付草案
1. 用清楚的逐日格式列出草案（Day 1：順序、每站交通時間、當日總時數），附上套票建議與所有警示（缺座標、休館衝突、待確認菜單、必去景點沖堂）
2. **等使用者確認或調整後**，才把最終順序、日期時間交給 `travel-map-trip-planner` 去建立/更新對應的 `行程項目`（含 `日期時間`、`所屬旅程`、`相關見聞錄`）——本 skill 到這裡結束，不自己動筆寫 Notion

## 規則
- 距離計算是直線距離（haversine）換算成粗估時間，**不是實際導航時間**，跟使用者說清楚這是概估，不是精確路線
- 沒有座標的點寧可跳過並提醒，不要憑印象排進動線
- 排好的草案沒有經過使用者確認前，不要叫 `travel-map-trip-planner` 動筆
- 套票、開放時間這類會隨時間變動的資訊，沿用 `travel-map-page-content` 查到的內容，自己不额外查證

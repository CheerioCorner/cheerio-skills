# 同行者飲食檔案

> 判定「這間餐廳誰能吃」的唯一依據。任何要推薦餐廳、判定 `飲食適配` 欄位、
> 或排一趟旅程的餐廳時，先讀這份檔案，不要憑店名或菜系猜。
> 最後更新：2026-09-06

## 成員限制

| 成員 | 限制 | 判定重點 |
|------|------|----------|
| Cheer | 無 | 吃牛。喜歡當地特色美食與有水準的小甜點。 |
| 媽媽 | **不吃牛** | 不是整間店不能有牛，而是**必須有份量足夠的非牛主餐**。只有牛肉專門店（燒肉/牛排館/牛肉麵專賣）才算不適合。 |
| 爸爸 | **不能吃太鹹** | 重口味菜系（重鹽滷味、鹹香系拉麵、重口川菜、醃漬類為主）要標註。能不能客製「少鹽」是加分項。 |
| 女朋友 | **吃素** | 偏好**原型食物**的素食（蔬菜、豆腐、菇類、穀物）。**不喜歡加工素肉**（素雞素鴨、植物肉排、仿葷製品）。葷素混合餐廳要確認素食餐點是認真做的，不是只有一道生菜沙拉或炒青菜充數。 |

## 判定規則

判定 `飲食適配` 欄位時逐條檢查，**每一條都要指出依據**（菜單頁面、官網、評論裡有人提到、Google Maps 相片）：

- `🐄 有非牛主餐` — 菜單上至少有 2 道以上非牛的主餐選項
- `🥬 有素食主餐` — 有真正的素食主餐，不是配菜或沙拉
- `🌿 純蔬食餐廳` — 整間店蔬食（此時 🐄 自動成立）
- `🥕 原型食物友善` — 素食餐點以蔬菜/豆腐/菇/穀物為主，不是靠加工素肉撐場
- `🧂 可要求少鹽` — 口味本身偏清淡，或評論/官網顯示可客製調味
- `✅ 全家皆可` — **結論欄**。要同時滿足「有非牛主餐」＋「有素食主餐」＋（原型食物友善 或 口味不重）才給
- `⚠️ 部分成員不適合` — 有明確踩雷（例：牛肉專門店、全店重鹹、素食只有一道燙青菜）
- `❓ 待確認菜單` — **查不到菜單就填這個**。不要空著，也不要樂觀推測。

## 寫進頁面正文的格式

見聞錄（餐廳）的「🍽️ 飲食適配」一節固定四行：

```
非牛主餐：有／無／待確認 —— [依據]
素食主餐：有（原型／加工素肉為主）／無／待確認 —— [依據]
口味鹹度：清淡／中等／偏重／待確認 —— [依據]
結論：全家皆可 / 誰不適合、為什麼
```

## 常見誤判

- **日式燒肉店**：不是自動出局。多數有豬雞海鮮，媽媽有得吃；但素食通常只有生菜，女朋友會餓 → `⚠️`
- **印度菜／中東菜**：素食傳統強且多為原型食物，通常是全家最安全的選項
- **標榜「蔬食」的台式素食自助餐**：常大量使用加工素料且偏鹹，兩條都踩 → 不要因為是素食就給高分
- **米其林/高評分不等於適配**：評分高但只有 tasting menu、無法客製的店，反而風險高，要標註
